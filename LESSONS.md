# Lessons from merged work

AI Arena is built largely by coding agents. After a batch of merged work, we
review what had to be fixed again, what shouldn't have merged and what was
verified too thinly, and write it down here. Read this before changing code.

Each lesson has three parts:

1. **The rule**, in bold: what to do.
2. **Why**: what goes wrong without it.
3. **Evidence**: the commits, issues or PRs where it happened.

"Seen N×" counts the separate days a review found the same problem. A lesson
seen on 3 separate days moves into [docs/code-standards.md](docs/code-standards.md)
and is listed under "Moved to the code standards" below.
