# Write a social media thread

Audience: a technical buyer evaluating options. Product: a fictional event ingestion service. Separate confirmed capabilities from assumptions.

Task variant 4: make this response distinct and tailored to the audience and constraints above. Do not claim facts, metrics, customer quotes, or capabilities that were not provided.
