Implement `merge_intervals(intervals)` in `solution.py`. Each interval is a pair of integers `(start, end)` with `start <= end`, given as a list or tuple, and the input list is in no particular order. Return a new list of `[start, end]` lists sorted by start, merging intervals that overlap or touch (`[1, 3]` and `[3, 5]` become `[1, 5]`). An interval inside another is absorbed. Do not modify the input.
