Implement `parse_port(text)` in `solution.py`. It accepts only a string of ASCII digits 0-9 that denotes a TCP port from 1 through 65535, and returns it as an `int`. Leading zeros are allowed (`"0080"` is 80). It raises `ValueError` for everything else: an empty string, surrounding or embedded whitespace, a sign, an underscore, a non-ASCII digit, any other non-digit character, zero, or a value above 65535.
